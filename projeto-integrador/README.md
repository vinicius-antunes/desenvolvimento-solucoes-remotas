# Unidade VI — Projeto Integrador: Desenvolvimento de uma Solução Remota

**Status:** proposta ainda não desenvolvida. Este arquivo apenas organiza os itens exigidos na descrição repassada pelo professor.

## Objetivo da atividade

Propor uma solução para uma organização que necessite implementar ou melhorar a estrutura de trabalho remoto.

## Itens exigidos

- [ ] Definição da organização e do problema
- [ ] Levantamento de necessidades e requisitos
- [ ] Identificação dos usuários e de seus perfis
- [ ] Infraestrutura necessária
- [ ] Ferramentas e plataformas para trabalho remoto
- [ ] Políticas de comunicação, acesso e uso
- [ ] Usabilidade e acessibilidade
- [ ] Arquitetura de rede
- [ ] Segurança da informação
- [ ] Estimativa de custos
- [ ] Diagrama da solução
- [ ] Apresentação final da proposta
